## 캡처 참고

- 플레이 화면의 카메라 영역은 캡처 환경에서 카메라 권한을 사용하지 않은 상태일 수 있습니다.
- 실제 브라우저에서 카메라 권한을 허용하면 같은 UI 안에 사용자 카메라 영상이 표시됩니다.
- 공개 저장소에 업로드하기 전 닉네임·프로필 이미지·이메일 등 공개 여부를 최종 확인하세요.
